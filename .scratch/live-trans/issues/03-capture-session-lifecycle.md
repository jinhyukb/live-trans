# 03 — 캡처 세션 가동/중지 연결

**What to build:** 번역 토글과 화면 캡처·PiP 오버레이를 연결한다. 번역 세션이 시작되면 화면 캡처가 켜지고 PiP 오버레이가 뜨며, 세션이 종료되면(앱 토글 off 또는 PiP 닫기) 캡처와 오버레이가 함께 중지된다.

**Blocked by:** 01 — 앱 스캐폴드 + 번역 세션 토글, 02 — 캡처·오버레이 스파이크

**Status:** ready-for-agent

- [ ] 토글 on 시 캡처가 시작되고 라이브 PiP 오버레이가 다른 앱 위에 표시된다
- [ ] 토글 off 또는 PiP 닫기 시 캡처가 중지되고 오버레이가 사라진다
- [ ] 번역 세션 시작 중에 권한이 없으면 사용자에게 권한 요청 흐름을 안내한다
- [ ] 세션이 active인 동안 앱이 백그라운드에 있어도 캡처가 유지된다
