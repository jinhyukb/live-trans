# live-trans — v1 Spec

## 개요

다른 앱의 화면에 표시된 텍스트를 실시간으로 감지해 한국어로 번역해서 보여주는 iOS 화면 번역 앱. 번역 토글을 켜면 다른 앱(주로 브라우저)을 탐색하는 동안 화면 속 텍스트와 이미지 속 텍스트를 자동으로 번역한다. iOS 18+를 대상으로 하며 이후 안드로이드/데스크톱으로 확장할 계획이다.

## 목표 / 비목표

**목표**
- 웹 브라우저의 화면 속 텍스트를 실시간으로 자동 번역 (플로팅 캡션)
- 웹툰/만화 대사 같은 이미지 속 텍스트를 자동으로 제자리 번역
- 무료(번역 엔진 비용 제로) 하에서 품질과 속도 최대화

**비목표 (이후 단계)**
- 실시간 영상 자막/스트리밍 번역
- 특정 웹툰/게임 전용 앱 커버리지 (모든 앱 확장)
- 원문 제거 + 원작 톤 렌더링의 초고품질 제자리 번역
- 안드로이드/데스크톱 지원

## 주요 결정

- **표시**: 하이브리드 — 화면 속 텍스트는 플로팅 캡션(PiP 창, 연속), 이미지 속 텍스트는 제자리 번역(전체 화면 스냅샷)
- **캡처**: ReplayKit 브로드캐스트 → 로컬 루프백 → PiP 오버레이, iOS 18+ (ADR-0002)
- **번역 엔진**: 온디바이스 Apple Translation 기본, 품질 중요 작업은 Papago 무료 API 보강, 쿼터 소진 시 폴백 (ADR-0001)
- **전환**: 이미지 속 텍스트 감지 시 완전 자동으로 제자리 번역, 스냅샷 고정, 탭/스와이프로 닫음
- **감지**: 화면 변화 감지 기반 (배터리 절약), 연속 폴링 아님
- **구조**: iOS 네이티브 우선, 번역 파이프라인 오케스트레이션 로직과 UI를 분리하는 경계 유지
- **개발 환경**: Mac 없이 Windows 전용 개발. 순수 Swift 코어(`LiveTransCore`, Apple 프레임워크 미사용)는 Windows `swift test`로 TDD, iOS 셸(ReplayKit/PiP/SwiftUI)은 GitHub Actions macOS 러너로 빌드·서명 후 TestFlight로 실기기 검증 (ADR-0003)

## 표준안 (확정)

1. **소스 언어**: 화면 텍스트에서 자동 감지 (영어/일본어 포함, 그 외 언어도 자동 인식). 대상 언어는 한국어 고정. 감지 실패 시 플로팅 캡션에서 수동 지정.
2. **플로팅 캡션 조작**: 시스템 PiP 닫기 = 번역 세션 종료(확인 후), 창 탭 = 일시정지/재개. live-trans 앱의 토글이 세션 시작/종료의 정식 경로.
3. **OCR 필터링**: 1~2글자 단독 글자, 숫자/기호만, 이미 한국어인 텍스트, 동일 문자열 반복은 번역 제외 — 캡션/제자리 번역 노이즈 감소.
4. **세션 유지**: 앱을 닫아도 PiP와 번역 세션은 유지. 사용자가 off하거나 PiP를 닫을 때까지 계속.
5. **이행 순서**: ① 캡처·오버레이 스파이크 ② 화면 속 텍스트 PiP 번역 ③ 제자리 번역 자동 전환.

## v1 완료 기준

- 웹 브라우저의 화면 속 텍스트를 플로팅 캡션으로 연속 번역
- 웹툰/만화 대사(이미지 속 텍스트)를 자동 전환으로 제자리 번역
- 위와 별개로, 번역 세션 토글 on/off가 의도대로 동작

## 티켓 의존 구조

```
01 스캐폴드+토글 ────────────┐
                             ├→ 03 캡처 세션 → 04 화면속 텍스트 → 05 캡션 품질 ┐
02 캡처·오버레이 스파이크 ───┘                                                 ├→ 08 v1 마감
                              04 → 06 제자리 번역 → 07 Papago 캐스케이드 ───────┘
```

- 01, 02: 병렬 가능 (블로커 없음)
- 03: 01, 02 이후 / 04: 03 이후 / 05: 04 이후 / 06: 04 이후 / 07: 06 이후 / 08: 05, 07 이후
