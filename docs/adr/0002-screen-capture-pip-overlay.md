# 화면 캡처 — ReplayKit 브로드캐스트 → 로컬 루프백 → PiP 오버레이

iOS에는 다른 앱의 화면을 배경에서 직접 읽거나 그 위에 상시 UI를 띄우는 공식 API가 없다. 그래서 v1은 이미 검증된 우회 기법을 채택한다: ReplayKit 브로드캐스트 익스텐션이 전체 화면 프레임을 로컬 루프백(앱 내부 서버)으로 전달하고, 앱은 그 스트림을 AVPlayer로 재생해 "그림 속 그림(PiP)" 창으로 최상위에 띄운다. 번역 캡션은 그 PiP 영상 콘텐츠 위에 합성한다.

이 방식은 iOS 18+를 대상으로 하며 사용자에게 화면 녹화 권한이 필요하다. iOS 26의 ScreenCaptureKit이 백그라운드 전체 화면 캡처를 공식 지원하지만, v1은 도달 범위를 위해 검증된 방식을 고르고 SCKit 채택률이 충분히 오르면 이전하는 것을 열어둔다.
