# 번역 엔진 캐스케이드 — 온디바이스 기본 + 무료 클라우드 보강

무료(번역 엔진 비용 제로)를 하드 제약으로 두면서 품질과 속도를 최대화하기로 결정했다. 연속 자동 번역(플로팅 캡션)은 온디바이스 Apple Translation이 담당하고(무제한 무료, 즉각 응답, 프라이버시), 품질이 중요한 제자리 번역과 같은 사용자 트리거 작업은 Naver Papago 무료 API(일 10,000자 한도)가 보강하며, 쿼터 소진 시 온디바이스 결과로 폴백한다.

무료 클라우드 API의 한도가 연속 번역량을 감당할 수 없어, "속도는 온디바이스가, 품질은 한정된 무료 클라우드 쿼터가" 담당하도록 트랙을 분리했다.
